# Screenshots

Drop your project images in this folder. The main `README.md` references these
filenames — match them and the images appear automatically:

| Filename | Shown as |
| -------- | -------- |
| `spotlight.png`  | Spotlight search |
| `workspace.png`  | Workspace view |
| `newtab.png`     | New-tab dashboard |
| `capture.png`    | Note capture |
| `active.png`     | Active apps & windows |
| `share.png`      | Share & sync |

You can add more and reference them from the README, or rename these and update
the README's image paths to match.

**Tips:** PNG or WebP, ~1200–1600px wide, and keep file sizes reasonable so the
repo stays light.
