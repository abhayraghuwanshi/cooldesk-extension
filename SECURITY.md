# Security Policy

## Reporting a vulnerability

Please don't open a public issue for security problems.

Report privately through GitHub: **Security → Report a vulnerability** on this repository. Include the affected version, platform (Chrome extension or desktop app + OS), and steps to reproduce.

You'll get a reply within a few days. Fixes ship in the next release.

## Supported versions

Only the latest release of the extension and the desktop app gets security fixes.
